Configuration Firebase

Setup (5 min, gratuit) :
  1. Va sur console.firebase.google.com
  2. Clique "Add project" → donne un nom → continue (désactive Analytics)
  3. Dans le menu de gauche : "Build → Realtime Database"
  4. Clique "Create Database" → choisis une région → mode "test" (lecture/écriture publique)
  5. Va dans ⚙️ "Project settings" → "Your apps" → icône </> (web)
  6. Donne un surnom à l'app, ignore "Hosting" → "Register"
  7. Copie apiKey et databaseURL ci-dessous
